# Moja Gra

Wieloosobowa gra .io w przeglądarce (Node.js, Express, Socket.IO, Canvas).

## Uruchomienie lokalnie

```
npm install
npm start
```

Otwórz http://localhost:3000. Hostowanie: Railway (zmienna `PORT` ustawia platforma).

## Zasady

Steruj myszką lub palcem. Zbieraj kulki, rośnij i zjadaj mniejszych graczy.
